# ASM integration
Reserve project/ for the native ASM/ModelDesk setup and adapters/ for controller coupling.
Future adapters convert ASM measurements to A3 states and force/moment requests to physical actuator inputs.
Validate wheel ordering, torque signs, steering conventions, saturation and sampling against the actual ASM configuration.
A11 is the starting specification, not evidence of a completed integration. No ASM model or allocation layer has been created.
